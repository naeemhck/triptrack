TripTrack Account & Data Deletion Request

TripTrack provides authenticated in-app account deletion and a static email request option for users who cannot access the app.

Method 1: In-App Instant Deletion (Recommended)

  1. Open the TripTrack app on your iOS or Android device.
  2. Navigate to Trip List / Profile Settings screen.
  3. Tap the red "Delete Account" button at the bottom of the screen.
  4. Confirm the prompt. TripTrack stops local tracking, requests server-side cleanup, and reports success only after the Supabase Auth account is deleted.

Method 2: Web Deletion Request Form

If you no longer have access to TripTrack, this form opens your email application to send a request to support. It is not an automated deletion endpoint, and identity verification is required before processing.

What Data Is Deleted?

  • Supabase Auth Account: Permanently deleted after server cleanup succeeds.
  • User Profile: Private profile fields are removed or anonymized where historical integrity requires retention.
  • Push Notification Tokens: Expo push tokens are deleted from Supabase.
  • Background Location Watcher: Tracking task and local async state cleared.
  • Trip Membership: Eligible non-organizer memberships are removed. Organizer references may be retained with an anonymized profile to preserve trip history.
